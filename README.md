# 🚀 JavaScript Practice Hub

Набор практических заданий и примеров на JavaScript.  
Проект создан для закрепления базовых и продвинутых концепций языка.

---

## 📌 О проекте

Этот репозиторий содержит решения задач и эксперименты с JavaScript.  
Основная цель — прокачка навыков разработки и понимание core-механик языка.

---

## 🧠 Что изучается

- 🔹 Переменные и типы данных  
- 🔹 Функции и области видимости  
- 🔹 Массивы и объекты  
- 🔹 Асинхронность (Promise, async/await)  
- 🔹 Работа с API  
- 🔹 Основы ООП в JavaScript  

---

## ⚙️ Технологии

- JavaScript (ES6+)
- Node.js (при необходимости)
- Fetch API
